## 🚀 What I'm Building

<table>

<td width="50%">

### ☁️ [Crawlee Cloud](https://github.com/crawlee-cloud)
**Self-hosted apify alternative platform** — Run Crawlee/Apify actors on your own infrastructure with full control.

- 🔒 **Privacy-first** — Your data stays on YOUR servers
- 💰 **Cost-effective** — No per-actor pricing
- 🐳 **Docker-native** — Deploy anywhere
- 🔧 **SDK Compatible** — Works with existing Crawlee/Apify actors

**→ [Star it on GitHub](https://github.com/crawlee-cloud)**

</td>
<td width="50%">

### 🎯 Why I Built This
Working with enterprise clients, I kept hearing the same request: *"We need self-hosting for compliance."*

So I built **Crawlee Cloud** — a solution I can share across client projects and maintain as one codebase for everyone:

- 🏢 **Enterprise-ready** — Built for compliance & data residency
- 🔄 **One codebase** — Shared across projects, maintained centrally
- 💜 **Open source** — Community-driven, transparent

*Complementing the Crawlee ecosystem. Building in public! 👇*
